> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按 `docs/requirements/fetch-design-v0.12.md` 落地 `@meld-ts/core/fetch` 子路径：`createFetcher` 一条请求流水线、一种 `FetchError`、可注入的 `fetch` / `decode`、`readBody` / `successEnvelope`，零运行时依赖、声明里不出现 DOM 类型。

**Architecture:** `src/fetch/` 是新的第三层模块，只依赖 `types`。公开面拆成 `errors.ts` / `decode.ts` / `types.ts` / `allowNil.ts` / `fetcher.ts` 五个普通文件，`_internal.ts` 放私有 helper，`index.ts` 只做星号转发。请求侧在 `fetcher.ts` 内完成 URL / query / headers / body 的拼接与错误分类；`decode` 只翻译响应，`validate` / `transform` 由调用方给。

**Tech Stack:** Bun 1.4.x、TypeScript 5.9.3（devDep，支持范围 `>=5.9 <8`）、Biome 2.x（含 grit 转发禁令）、bunup。

**Spec:** `docs/requirements/fetch-design-v0.12.md`（含 2026-11-26 落地修订）

## Global Constraints

- 只用 bun；不引入 axios / node-fetch / undici 等运行时依赖。
- 遵守 AGENTS.md 的模块入口规则：`src/fetch/index.ts` 顶层只许星号转发；`_` 开头的文件私有；禁止任何跨文件转发（值、类型、别名、包装）。
- 模块分层：`fetch` 归第三层，运行时代码只 import `types`；`*.test.ts` 可以 import 其他公开入口（如 `traits`）做类型兼容验证，测试不进产物图。
- 声明里不出现 DOM 类型（`Response`、`RequestInit`、`AbortSignal`、`Headers`……）；默认值从 `globalThis.fetch` 推断。
- `FetchError` 是库唯一抛出的错误类型；取消、用法错误、`validate` / `transform` 自己抛的错原样上抛。
- `transform` 必须同步，类型层用 `SyncResult<R>` 拒绝 async。
- 保持仓库 100% 覆盖率（`bunfig.toml` 的 `coverageThreshold = 1`）。
- 代码风格：单引号、分号、2 空格、80 列；代码注释英文，文档中文。
- 提交信息用 conventional commits；每个 task 结束跑 `bun run lint`、`bun run ts-check`、`bun run test`（覆盖率 100%）。

```ts
import { isRecord } from './_internal';

export type FetchErrorKind = 'network' | 'status' | 'failure' | 'invalid';

export type FetchErrorOptions = {
  kind: FetchErrorKind;
  url: string;
  method: string;
  status?: number;
  failure?: unknown;
  body?: unknown;
  cause?: unknown;
};

/**
 * Brand shared across duplicated copies of this package, same rationale as
 * allowNil. `instanceof` must survive a renderer bundling its own copy of core.
 */
const FETCH_ERROR_BRAND: unique symbol = Symbol.for(
  '@meld-ts/core/fetch:FetchError',
);

export class FetchError extends Error {
  readonly name: 'FetchError' = 'FetchError';
  readonly kind: FetchErrorKind;
  readonly url: string;
  readonly method: string;
  readonly status: number | undefined;
  readonly failure: unknown;
  readonly body: unknown;

  static [Symbol.hasInstance](value: unknown): boolean {
    return isRecord(value) && FETCH_ERROR_BRAND in value;
  }

  constructor(message: string, options: FetchErrorOptions) {
    super(
      message,
      options.cause === undefined ? undefined : { cause: options.cause },
    );
    // A class field keyed by a custom symbol cannot be emitted under
    // isolatedDeclarations (TS9038), so install the brand here.
    Object.defineProperty(this, FETCH_ERROR_BRAND, { value: true });
    this.kind = options.kind;
    this.url = options.url;
    this.method = options.method;
    this.status = options.status;
    this.failure = options.failure;
    this.body = options.body;
  }
}

export type FetchErrorOf<Failure> = FetchError &
  (
    | { readonly kind: 'network'; readonly status: undefined }
    | { readonly kind: 'status'; readonly status: number }
    | {
        readonly kind: 'failure';
        readonly status: number;
        readonly failure: Failure;
      }
    | { readonly kind: 'invalid'; readonly status: number | undefined }
  );
```

```ts
/** application/json, application/*+json；参数（charset 等）忽略。 */
export const isJsonContentType = (value: string | null): boolean => {
  if (value === null) return false;
  const type = value.split(';', 1)[0]?.trim().toLowerCase();
  if (type === undefined) return false;
  return type === 'application/json' || type.endsWith('+json');
};
```

`decode.ts` 关键实现：

```ts
import { isJsonContentType, isRecord } from './_internal';

export type ResponseLike = {
  readonly status: number;
  readonly headers: { get(name: string): string | null };
  text(): Promise<string>;
};

export type DecodeContext = {
  readonly url: string;
  readonly method: string;
  readonly signal?: unknown;
};

export type Decoded<Failure> =
  | { kind: 'success'; data: unknown }
  | { kind: 'failure'; status: number; failure: Failure; message?: string }
  | { kind: 'unrecognized'; status: number; body: unknown };

export type Decode<Res, Failure> = (
  res: Res,
  ctx: DecodeContext,
) => Decoded<Failure> | Promise<Decoded<Failure>>;

export type BodyRead = {
  body: unknown;
  malformedJson: boolean;
};

export type SuccessEnvelopeFailure = {
  code: number | string | null;
  message: string | null;
};

export const readBody: (
  res: ResponseLike,
  ctx: DecodeContext,
) => Promise<BodyRead> = async (res, ctx) => {
  if (
    ctx.method === 'HEAD' ||
    res.status === 204 ||
    res.status === 205 ||
    res.status === 304
  ) {
    return { body: null, malformedJson: false };
  }
  const text = await res.text();
  if (text.trim() === '') return { body: null, malformedJson: false };
  if (!isJsonContentType(res.headers.get('content-type'))) {
    return { body: text, malformedJson: false };
  }
  try {
    const parsed: unknown = JSON.parse(text);
    return { body: parsed, malformedJson: false };
  } catch {
    return { body: text, malformedJson: true };
  }
};
```

`successEnvelope`：

```ts
export const successEnvelope: (keys?: {
  success?: string;
  data?: string;
  code?: string;
  message?: string;
}) => Decode<ResponseLike, SuccessEnvelopeFailure> = (keys = {}) => {
  const successKey = keys.success ?? 'success';
  const dataKey = keys.data ?? 'data';
  const codeKey = keys.code ?? 'code';
  const messageKey = keys.message ?? 'message';

  return async (res, ctx) => {
    const { body, malformedJson } = await readBody(res, ctx);
    const ok = res.status >= 200 && res.status <= 299;

    if (malformedJson) {
      return { kind: 'unrecognized', status: res.status, body };
    }
    if (body === null && ok) return { kind: 'success', data: null };
    if (!isRecord(body)) {
      return { kind: 'unrecognized', status: res.status, body };
    }

    const success = body[successKey];
    if (success === true && ok) {
      return { kind: 'success', data: body[dataKey] };
    }
    if (success === false) {
      const code = body[codeKey];
      const rawMessage = body[messageKey];
      const message =
        typeof rawMessage === 'string' && rawMessage !== '' ? rawMessage : null;
      return {
        kind: 'failure',
        status: res.status,
        failure: {
          code: typeof code === 'number' || typeof code === 'string' ? code : null,
          message,
        },
        ...(message === null ? {} : { message }),
      };
    }
    return { kind: 'unrecognized', status: res.status, body };
  };
};
```

```ts
    : { fetch: unknown; decode: unknown };

type CleanInit<Init> = NonNullable<Init>;
type InitField<Init, K extends PropertyKey> = K extends keyof CleanInit<Init>
  ? NonNullable<CleanInit<Init>[K]>
  : never;
type InitExtras<Init> = Omit<
  CleanInit<Init>,
  'method' | 'headers' | 'body' | 'signal'
>;

export type SendOptions<Init> = {
  method?: string;
  path: string;
  query?: Record<string, QueryValue | readonly QueryValue[]>;
  headers?: HeaderValues;
  signal?: InitField<Init, 'signal'>;
  init?: InitExtras<Init>;
} & (
  | { json?: unknown; body?: never }
  | { body?: InitField<Init, 'body'>; json?: never }
);

export type ParseOptions<T, R, Res = unknown> = {
  validate?: (val: unknown, res: Res) => val is T;
  transform?: (input: T, res: Res) => SyncResult<R>;
};

export type AllowNilOptions<T, R, Res = unknown> = {
  validate: AllowNil;
  transform?: (input: T | null, res: Res) => SyncResult<R>;
};

export interface Fetcher<Res, Init, Failure> {
  request<T = unknown, R = T | null>(
    opts: SendOptions<Init> & AllowNilOptions<T, R, Res>,
  ): Promise<NoInfer<R>>;
  request<T = unknown, R = T>(
    opts: SendOptions<Init> & ParseOptions<T, R, Res>,
  ): Promise<NoInfer<R>>;
  raw(opts: SendOptions<Init>): Promise<Res>;
  isFetchError(err: unknown): err is FetchErrorOf<Failure>;
}

// biome-ignore lint/suspicious/noExplicitAny: only Init is read
export type InitOf<F> = F extends Fetcher<any, infer Init, any> ? Init : never;
// biome-ignore lint/suspicious/noExplicitAny: only Res is read
export type ResOf<F> = F extends Fetcher<infer Res, any, any> ? Res : never;
```

```ts
export type QueryValue = string | number | boolean | null | undefined;

export type SyncResult<T> = T extends PromiseLike<unknown> ? never : T;

export const joinUrl = (baseUrl: string | undefined, path: string): string => {
  if (!baseUrl) return path;
  if (/^(?:https?:)?\/\//i.test(path)) return path;
  const left = baseUrl.replace(/\/+$/, '');
  const right = path.replace(/^\/+/, '');
  if (right === '') return left === '' ? '/' : left;
  return left === '' ? `/${right}` : `${left}/${right}`;
};

const encodeQueryKey = (key: string): string =>
  encodeURIComponent(key).replace(/%5B/gi, '[').replace(/%5D/gi, ']');

export const appendQuery = (
  url: string,
  query: Record<string, QueryValue | readonly QueryValue[]> | undefined,
): string => {
  if (!query) return url;
  const parts: string[] = [];
  for (const [key, value] of Object.entries(query)) {
    const encodedKey = encodeQueryKey(key);
    const values = Array.isArray(value) ? value : [value];
    for (const item of values) {
      if (item === null || item === undefined) continue;
      parts.push(`${encodedKey}=${encodeURIComponent(String(item))}`);
    }
  }
  if (parts.length === 0) return url;
  if (!url.includes('?')) return `${url}?${parts.join('&')}`;
  if (url.endsWith('?') || url.endsWith('&')) return url + parts.join('&');
  return `${url}&${parts.join('&')}`;
};

export const collectHeaders = (
  target: Map<string, string>,
  values: Readonly<Record<string, string | null | undefined>> | undefined,
  deleteNull: boolean,
): void => {
  if (!values) return;
  for (const [key, value] of Object.entries(values)) {
    const normalized = key.toLowerCase();
    if (value === undefined) continue;
    if (value === null) {
      if (deleteNull) target.delete(normalized);
      continue;
    }
    target.set(normalized, value);
  }
};

export const isAborted = (signal: unknown): boolean =>
  typeof signal === 'object' &&
  signal !== null &&
  'aborted' in signal &&
  signal.aborted === true;

export const abortReason = (signal: unknown): unknown =>
  typeof signal === 'object' && signal !== null && 'reason' in signal
    ? signal.reason
    : undefined;

export const throwIfAborted = (signal: unknown): void => {
  if (!isAborted(signal)) return;
  const reason = abortReason(signal);
  if (reason !== undefined) throw reason;
  const error = new Error('The operation was aborted.');
  error.name = 'AbortError';
  throw error;
};
```

```ts
import {
  appendQuery,
  collectHeaders,
  isRecord,
  joinUrl,
  MSG_BODY_NOT_ALLOWED,
  MSG_DECODE_REQUIRED,
  MSG_INVALID_DATA,
  MSG_INVALID_RESPONSE,
  MSG_JSON_NOT_SERIALIZABLE,
  MSG_NETWORK,
  MSG_NO_FETCH,
  MSG_REQUEST_FAILED,
  MSG_VALIDATE_INVALID,
  throwIfAborted,
} from './_internal';
import { allowNil } from './allowNil';
import {
  readBody,
  type Decode,
  type Decoded,
  type ResponseLike,
} from './decode';
import { FetchError, type FetchErrorOf } from './errors';
import type {
  DefaultInit,
  DefaultRes,
  Fetcher,
  FetcherOptions,
  FetchInit,
  FetchLike,
  RequireFor,
  SendOptions,
} from './types';

type InternalRequestOptions<Init, Res> = SendOptions<Init> & {
  validate?: unknown;
  transform?: (input: unknown, res: Res) => unknown;
};

type BuiltRequest<Init> = {
  url: string;
  method: string;
  init: Init & FetchInit;
  signal: unknown;
};

const is2xx = (status: number): boolean => status >= 200 && status <= 299;

const isResponseLike = (value: unknown): value is ResponseLike =>
  isRecord(value) &&
  typeof value.status === 'number' &&
  isRecord(value.headers) &&
  typeof value.headers.get === 'function' &&
  typeof value.text === 'function';

const isDecoded = <Failure>(value: unknown): value is Decoded<Failure> => {
  if (!isRecord(value)) return false;
  switch (value.kind) {
    case 'success':
      return 'data' in value;
    case 'failure':
      return (
        typeof value.status === 'number' &&
        Number.isFinite(value.status) &&
        'failure' in value
      );
    case 'unrecognized':
      return (
        typeof value.status === 'number' &&
        Number.isFinite(value.status) &&
        'body' in value
      );
    default:
      return false;
  }
};

const defaultDecode: Decode<ResponseLike, never> = async (res, ctx) => {
  const { body, malformedJson } = await readBody(res, ctx);
  if (!is2xx(res.status) || malformedJson) {
    return { kind: 'unrecognized', status: res.status, body };
  }
  return { kind: 'success', data: body };
};

const makeInvalid = (
  message: string,
  url: string,
  method: string,
  extra?: { status?: number; body?: unknown; cause?: unknown },
): FetchError =>
  new FetchError(message, { kind: 'invalid', url, method, ...extra });

export function createFetcher<
  Res = DefaultRes,
  Init = DefaultInit,
  Failure = never,
>(
  ...args: [DefaultRes] extends [never]
    ? [opts: FetcherOptions<Res, Init, Failure> & RequireFor<Res>]
    : [opts?: FetcherOptions<Res, Init, Failure> & RequireFor<Res>]
): Fetcher<Res, Init, Failure> {
  const options = (args[0] ?? {}) as FetcherOptions<Res, Init, Failure>;
  const headersOption = options.headers;
  const staticHeaders = (() => {
    if (headersOption === undefined || typeof headersOption === 'function') {
      return undefined;
    }
    const map = new Map<string, string>();
    collectHeaders(map, headersOption, false);
    return map;
  })();
  const onError = options.onError;
  const decodeOption = options.decode;
  const thrown = new WeakSet<object>();

  const fail = (error: FetchError): never => {
    thrown.add(error);
    const replacement = onError?.(error as FetchErrorOf<Failure>);
    if (replacement instanceof Error) throw replacement;
    throw error;
  };

  const resolveFetch = (): FetchLike<Res, Init> => {
    const candidate =
      options.fetch ?? (globalThis as { fetch?: unknown }).fetch;
    if (typeof candidate !== 'function') throw new TypeError(MSG_NO_FETCH);
    // Callability is checked above; the public signature constrains the shape.
    return candidate as FetchLike<Res, Init>;
  };

  const buildRequest = async (
    opts: SendOptions<Init>,
  ): Promise<BuiltRequest<Init>> => {
    const signal = opts.signal;
    throwIfAborted(signal);

    const method = (opts.method ?? 'GET').toUpperCase();
    const hasJson = opts.json !== undefined;
    const hasBody = hasJson || opts.body !== undefined;
    if ((method === 'GET' || method === 'HEAD') && hasBody) {
      throw new TypeError(MSG_BODY_NOT_ALLOWED);
    }

    const url = appendQuery(joinUrl(options.baseUrl, opts.path), opts.query);

    let body: unknown;
    if (hasJson) {
      body = JSON.stringify(opts.json);
      if (body === undefined) throw new TypeError(MSG_JSON_NOT_SERIALIZABLE);
    } else {
      body = opts.body;
    }

    const requestOnly = new Map<string, string>();
    collectHeaders(requestOnly, opts.headers, false);
    const preview = new Map(requestOnly);
    if (hasJson && !preview.has('content-type')) {
      preview.set('content-type', 'application/json');
    }

    let instanceHeaders: Map<string, string>;
    if (typeof headersOption === 'function') {
      const values = await headersOption({
        url,
        method,
        headers: Object.fromEntries(preview),
        body,
      });
      instanceHeaders = new Map();
      collectHeaders(instanceHeaders, values, false);
    } else {
      instanceHeaders = new Map(staticHeaders ?? []);
    }

    const merged = new Map(instanceHeaders);
    collectHeaders(merged, opts.headers, true);
    if (hasJson && !merged.has('content-type')) {
      merged.set('content-type', 'application/json');
    }

    const init = {
      ...(opts.init ?? {}),
      method,
      headers: Object.fromEntries(merged),
      ...(body === undefined ? {} : { body }),
      ...(signal === undefined ? {} : { signal }),
    } as Init & FetchInit;

    return { url, method, init, signal };
  };

  const callFetch = async (built: BuiltRequest<Init>): Promise<Res> => {
    const fetchImpl = resolveFetch();
    try {
      return await fetchImpl(built.url, built.init);
    } catch (cause) {
      throwIfAborted(built.signal);
      throw fail(
        new FetchError(MSG_NETWORK, {
          kind: 'network',
          url: built.url,
          method: built.method,
          cause,
        }),
      );
    }
  };

  const raw = async (opts: SendOptions<Init>): Promise<Res> =>
    callFetch(await buildRequest(opts));

  const request = async (
    opts: InternalRequestOptions<Init, Res>,
  ): Promise<unknown> => {
    const built = await buildRequest(opts);
    const res = await callFetch(built);

    if (decodeOption === undefined && !isResponseLike(res)) {
      throw new TypeError(MSG_DECODE_REQUIRED);
    }
    const decodeFn = (decodeOption ?? defaultDecode) as Decode<Res, Failure>;
    // When decode is omitted, RequireFor guarantees Res extends ResponseLike;
    // TS cannot express that correlation between the two generic parameters.

    let decoded: unknown;
    try {
      decoded = await decodeFn(res, {
        url: built.url,
        method: built.method,
        signal: built.signal,
      });
    } catch (cause) {
      throwIfAborted(built.signal);
      throw fail(
        makeInvalid(MSG_INVALID_RESPONSE, built.url, built.method, { cause }),
      );
    }
    throwIfAborted(built.signal);

    if (!isDecoded<Failure>(decoded)) {
      throw fail(makeInvalid(MSG_INVALID_RESPONSE, built.url, built.method));
    }

    if (decoded.kind === 'failure') {
      throw fail(
        new FetchError(decoded.message ?? MSG_REQUEST_FAILED, {
          kind: 'failure',
          url: built.url,
          method: built.method,
          status: decoded.status,
          failure: decoded.failure,
        }),
      );
    }

    if (decoded.kind === 'unrecognized') {
      if (is2xx(decoded.status)) {
        throw fail(
          makeInvalid(MSG_INVALID_RESPONSE, built.url, built.method, {
            status: decoded.status,
            body: decoded.body,
          }),
        );
      }
      throw fail(
        new FetchError(`HTTP ${decoded.status}`, {
          kind: 'status',
          url: built.url,
          method: built.method,
          status: decoded.status,
          body: decoded.body,
        }),
      );
    }

    const data = decoded.data === undefined ? null : decoded.data;
    const validate = opts.validate;

    if (validate === allowNil) {
      // accepted as-is
    } else if (validate === undefined) {
      if (data === null) {
        throw fail(
          makeInvalid(
            `${MSG_INVALID_DATA} Pass validate: allowNil for endpoints that return null.`,
            built.url,
            built.method,
            { body: data },
          ),
        );
      }
    } else if (typeof validate === 'function') {
      // Runtime callability is checked; the public type constrains the shape.
      const guard = validate as (value: unknown, res: Res) => boolean;
      if (!guard(data, res)) {
        throw fail(
          makeInvalid(MSG_INVALID_DATA, built.url, built.method, {
            body: data,
          }),
        );
      }
    } else {
      throw new TypeError(MSG_VALIDATE_INVALID);
    }

    return opts.transform === undefined ? data : opts.transform(data, res);
  };

  const isFetchError = (err: unknown): err is FetchErrorOf<Failure> =>
    typeof err === 'object' && err !== null && thrown.has(err);

  return {
    // The two overloads cannot share one expressible implementation signature;
    // the runtime shape handles both.
    request: request as Fetcher<Res, Init, Failure>['request'],
    raw,
    isFetchError,
  };
}
```

- [ ] **Step 5: 核对请求顺序与字段表**

实现完成后对照设计稿逐条核对：

1. `resolveFetch()` 每次调用时读 `options.fetch ?? globalThis.fetch`，`typeof !== 'function'` 抛 `TypeError(MSG_NO_FETCH)`。
2. `callFetch` 用 `await fetchImpl(url, init)`（解构后调用，不带 this）；reject 时先 `throwIfAborted(signal)`，再 `fail(networkError)`。
3. `fail` 先 `thrown.add(error)`，再调 `onError`；`onError` 返回 `instanceof Error` 就抛它，否则抛原错误。
4. `raw` = `callFetch(await buildRequest(opts))`。
5. `request` 在无 `options.decode` 且 `!isResponseLike(res)` 时抛 `TypeError(MSG_DECODE_REQUIRED)`（不经过 onError）。
6. invalid 四种来路的字段：
   - decode 抛错：`{ cause }`，无 status/body。
   - decode 非三种之一：无 status/body/cause。
   - unrecognized 2xx：`{ status, body }`。
   - validate 没过：`{ body: data }`，无 status。
7. 默认 validate：`data !== null`；失败消息用 `MSG_INVALID_DATA + ' Pass validate: allowNil for endpoints that return null.'`。
8. `validate === allowNil` 跳过；`undefined` 走默认；`typeof === 'function'` 调用；其余抛 `TypeError(MSG_VALIDATE_INVALID)`。
9. `transform` 只调用一次，第二参数是 `res`；不 await。
10. `isFetchError` 用 `typeof err === 'object' && err !== null && thrown.has(err)`。
