# @meld-ts/core/a11y CLI、用户模式与一致性测试（Plan C）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 交付 `meld-ts a11y probe` 用户模式（按项目自己的 lint 版本生成重载文件）、lint 一致性/反向测试（第 2、3 层）与构建产物重载测试（第 4 层），并把「不手写 role/aria」固化为仓库规则与 CI 检查。

**Tech Stack:** TypeScript 5.9.3、Bun 1.4.4、bunup（独立 bin 配置）、eslint + eslint-plugin-jsx-a11y、oxlint、@biomejs/biome、aria-query

`src/bin/meld-ts.ts`：

```ts
#!/usr/bin/env bun

export interface ProbeArgs {
  readonly lint?: readonly string[];
  readonly out?: string;
  readonly keep: boolean;
}

export const parseProbeArgs = (argv: readonly string[]): ProbeArgs => {
  let lint: string[] | undefined;
  let out: string | undefined;
  let keep = false;
  for (const arg of argv) {
    if (arg === '--keep') {
      keep = true;
      continue;
    }
    if (arg.startsWith('--lint=')) {
      const raw = arg.slice('--lint='.length);
      if (!raw) throw new Error('empty --lint');
      lint = raw.split(',');
      for (const name of lint) {
        if (!['eslint', 'bun', 'oxlint', 'biome'].includes(name)) {
          throw new Error(`unknown lint '${name}'`);
        }
      }
      continue;
    }
    if (arg.startsWith('--out=')) {
      out = arg.slice('--out='.length);
      continue;
    }
    throw new Error(`unknown argument: ${arg}`);
  }
  return { lint, out, keep };
};

const usage = `Usage:
  meld-ts a11y probe [--lint=biome,oxlint] [--out=./a11y-lints.generated.d.ts] [--keep]`;

export const main = async (argv: readonly string[]): Promise<number> => {
  const [group, command, ...rest] = argv;
  if (group !== 'a11y' || command !== 'probe') {
    console.error(usage);
    return 1;
  }
  try {
    const args = parseProbeArgs(rest);
    // user-mode implementation lands in Task 3
    console.error(
      `probe args ok: ${JSON.stringify(args)} (user mode not wired yet)`,
    );
    return 0;
  } catch (error) {
    console.error((error as Error).message);
    console.error(usage);
    return 1;
  }
};

if (import.meta.main) {
  process.exit(await main(process.argv.slice(2)));
}
```

`tsconfig-check.ts`：

```ts
export interface TsconfigCheckInput {
  readonly cwd: string;
  readonly outPath: string;
  readonly readJson: (path: string) => unknown;
}

const matches = (pattern: string, file: string): boolean => {
  if (pattern.endsWith('.d.ts')) return file.endsWith(pattern);
  if (pattern.includes('**')) {
    const suffix = pattern.slice(pattern.indexOf('*') + 2);
    return file.endsWith(suffix.replace(/^\//, ''));
  }
  return false;
};

export const checkTsconfigIncludes = ({
  cwd,
  outPath,
  readJson,
}: TsconfigCheckInput): { included: boolean; reason: string } => {
  const tsconfig = readJson(`${cwd}/tsconfig.json`) as {
    include?: string[];
    exclude?: string[];
  };
  const file = outPath.slice(cwd.length + 1);
  if ((tsconfig.exclude ?? []).some((p) => matches(p, file))) {
    return { included: false, reason: 'exclude' };
  }
  if ((tsconfig.include ?? []).some((p) => matches(p, file))) {
    return { included: true, reason: 'include' };
  }
  return { included: false, reason: 'not-include' };
};
```

`meld.ts` 的 `main`：

```ts
import { checkTsconfigIncludes } from '../a11y/probe/tsconfig-check';
import { detectLints } from '../a11y/probe/detect';
import { nodeExec } from '../a11y/probe/exec';
import { probe } from '../a11y/probe';
import { serializeOverride } from '../a11y/probe/emit-override';
import { ARIA_KEYS, NAME_RULES, SAMPLES } from '../a11y/probe/samples.generated';
import { existsSync, mkdirSync, readFileSync, rmSync, writeFileSync } from 'node:fs';

export const runProbe = async ({ cwd, lint, out, keep }: ProbeArgs): Promise<string> => {
  const detected = detectLints({
    cwd,
    exec: nodeExec,
    readJson: (p) => JSON.parse(readFileSync(p, 'utf8')),
    exists: existsSync,
  });
  const wanted = lint ?? detected.map((d) => d.name);
  const missing = wanted.filter((n) => !detected.some((d) => d.name === n));
  if (missing.length) throw new Error(`lint not installed: ${missing.join(', ')}`);

  const profiles = probe({
    cwd,
    detected: detected.filter((d) => wanted.includes(d.name)),
    runners: { eslint: runEslint, oxlint: runOxlint, biome: runBiome, bun: runBun },
    samples: SAMPLES,
    keys: ARIA_KEYS,
    nameRule: NAME_RULES,
    exec: nodeExec,
    fs: {
      mkdir: (p) => mkdirSync(p, { recursive: true }),
      write: (p, c) => writeFileSync(p, c),
      rm: (p) => rmSync(p, { recursive: true, force: true }),
    },
    keep,
  });

  const target = out ?? `${cwd}/a11y-lints.generated.d.ts`;
  writeFileSync(target, serializeOverride(profiles));
  const check = checkTsconfigIncludes({
    cwd,
    outPath: target,
    readJson: (p) => JSON.parse(readFileSync(p, 'utf8')),
  });
  if (!check.included) {
    console.warn(`warning: ${target} is not in tsconfig include (${check.reason}); the override will not take effect`);
  }
  return target;
};
```
